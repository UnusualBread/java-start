# Java Start

Учебный репозиторий для изучения Java с нуля.  
Включает базовые темы, мини-проекты и эксперименты.

## Структура

- `java_basics/` — темы по Java Core
- `mini_projects/` — маленькие приложения для практики
- `experiments/` — тесты и эксперименты
- `notes/` — заметки

## Как запустить

1. Открыть проект в IntelliJ IDEA
2. Запустить нужный файл через `main()` методом

## Примеры

```bash
cd java_basics/lesson_02_variables
javac Main.java
java Main
