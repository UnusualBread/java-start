# Учебный проект по Java — Hyperskill

В этом репозитории собраны мои решения заданий по курсу Java от JetBrains Academy.

## Структура

- `C02_java.M01_basics` — базовые темы
    - `M01_introduction_to_java` — введение в Java
    - `M02_types_and_variables` — типы и переменные
- Каждый модуль содержит уроки и задания с префиксами `Lxx` и `Txx`.

## Как запускать

Каждый класс — самостоятельное задание, можно запускать через IDE или команду:

```bash
javac path/to/T01_HelloWorld.java
java path.to.T01_HelloWorld
